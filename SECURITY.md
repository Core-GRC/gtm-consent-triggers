# Security

## Reporting a vulnerability

Please don't report security problems in public GitHub issues. Email support@core-grc.com with "Security" in the subject, or use **Report a vulnerability** on this repository's Security tab, and include:

- what you found and where (file, trigger or variable)
- steps to reproduce it

We'll acknowledge your report and keep you updated while we fix it.

## Supported versions

Only the latest `core-grc-consent-triggers.json` on `main` is supported. Download it again to get fixes.
